P21 Reconciliation — Proof of Concept

Reconciles a sample manifest / EDC extract against lab or vendor data — key matching, demographic cross-checks, and expected-sample validation. Everything below runs in this browser tab only: files are parsed in memory, nothing is uploaded, stored, or sent anywhere. Close the tab and it's gone.

Step 1 — Load your two data sources

Upload any CSV or Excel file for each side. Column names don't need to match — the next step figures that out for you. Or click "Load Demo Data" to try it instantly with a synthetic manifest-vs-lab dataset.

Step 5 — Expected-sample reconciliation

Independent of the identity-matching problem above: this checks whether each subject has every sample their cohort's plan expects — the same question as "were these samples expected, and do they exist." A plan (and any value aliases below) is safe to store/reuse — it's a protocol template, not subject data.

All three optional — pick "— none —" if the study doesn't need that dimension.

Sample plan

Edit inline, or import a plan file below (columns can be named anything — you map them). Cohort/Period/Timepoint are optional per row: leave blank to mean "applies regardless." Required: Y = error if missing, W = warning, O = optional/informational.

Value aliases (optional — for genuine cross-vendor terminology differences, not just formatting)

Case/punctuation differences ("PRE-DOSE" vs "Pre Dose") resolve automatically. A real vocabulary difference ("0H" meaning the same thing as "PRE-DOSE") won't — add an alias here rather than have it silently guessed. Applies to whichever source is being checked, never to the plan itself.
